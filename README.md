
# Calculadora de IMC

Programa en C++ para calcular y clasificar
el indice de masa corporal.

## Funciones
- Calculo del IMC
- Clasificacion del IMC
- Datos de pacientes de ejemplo

## Compilacion
g++ imc.cpp -o imc

## Ejecucion
./imc
